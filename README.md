# Equilibra — TCC

Protótipo acadêmico mobile-first para saúde mental, bem-estar, organização e estudos de estudantes.

## Stack
- React + TypeScript
- Vite
- Lucide Icons
- Recharts (preparado para dashboards)
- localStorage para persistência do protótipo

## Escopo
A aplicação implementa os fluxos definidos no documento do TCC: Home, check-in, diário, caixa de ideias, organização, calendário, tarefas, hábitos, estudos, Pomodoro, modo foco, sons, respiração, progresso, perfil, privacidade, instituição e ajuda.

Os dados institucionais são exclusivamente simulados e agregados. O protótipo não realiza diagnóstico e não substitui atendimento profissional.

## Rodar
`npm install`

`npm run dev`

O projeto foi estruturado para facilitar importação/evolução em ferramentas como Lovable.
